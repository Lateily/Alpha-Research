# Research Content Cards V1

Status: isolated offline implementation; no production or shared-service rollout.
Base: ba42de2e004a3cd920d21dc7a907dffe048dc665.

## Scope And Sequence

1. Keep material-research v1 immutable. Consume its externally pinned pack and
   reverify original PDFs, derived text, cutoff, citations and exact inventory.
2. Add a separate `ar.research-content-request.v1` and reproducible four-card
   output, not a silent upgrade of old UNRESOLVED reports.
3. Bind numeric observations to exact quote tokens, column positions, declared
   units and periods. Decimal arithmetic supports difference, ratio, percent
   change and an explicitly labelled annualization sensitivity. An arithmetic
   check does not verify the issuer, metric interpretation or forecast.
4. Require one substantive draft response per original question, with referenced
   facts/calculations, counterevidence and open questions. Responses remain
   analyst assertions, never automatic thesis scoring or human approval.
5. Semiconductors use the existing normalized-EPS valuation formula. Missing
   normalization, multiple or net-cash assumptions block a value band; a doubled
   half-year EPS is a sensitivity, not normalized EPS or a price target.
6. Recompute optional existing SMC/ICT frozen inputs through the existing engine.
   Do not fabricate minute bars from daily data or describe that engine as a
   daily strategy. The daily-first manual workflow remains an explicit pending
   input when no bound strategy evidence is supplied.
7. Execution feedback accepts an existing, externally pinned research-cycle
   bundle and its closure evidence only through the existing deterministic
   verifier. Separate thesis, valuation, timing, execution, portfolio and P&L.
   Missing feedback means NOT_SUPPLIED, not zero profit or proof of no orders.
8. Write a new local sealed report, request and JSON cards. Verify by rebuilding
   all bytes against the externally supplied pack/output hashes. No in-place
   mutation, new provider/model calls, approval inference or ledger writes.

## Acceptance

Normal, missing, contradictory and legacy inputs; quote/token/column/unit and
period disagreement; zero denominator, nonfinite values and duplicate IDs;
tampered and extra files; altered response, card or authority followed by a
self-reseal; cross-ticker/future strategy and feedback inputs; real historical
603986.SH material replay with old cutoff preserved. Behavioral mutation pins
must fail assertions. Same-final-source targeted/full offline verification and
fresh nonauthor review precede any completion claim. No merge, push, shared
upgrade or production change is included. Two-human acceptance stays deferred.

## Limits

This release is a local CLI/library vertical, not the next shared UI rollout.
The real example must not manufacture missing valuation, timing or execution
inputs to make four cards green. Source authenticity and redistribution/model
rights remain unverified. AI draft assessments and synthetic test scenarios are
not a U4 selection, paper authorization, forward sample or method validation.

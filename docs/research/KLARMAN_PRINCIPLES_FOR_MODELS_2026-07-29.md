## 四大原则 → 可计算规则

### 1. 不亏钱 / 安全边际（downside-first sizing）

原则：第一条规则是不亏钱，第二条是记住第一条。评估资产先算最差情形亏多少，不算最好情形赚多少；不做结构性必然产生亏损路径的操作（裸卖空、杠杆）。

案例结构（视频转述）：
- Mutual Shares 第一单：$8 买入，重组后返 $8 现金 + 免费获得连带公司股份 → **worst case = 保本，upside 免费**。
- SafeGuard (1991)：所持 Novell 股份市值 ≈ SafeGuard 整体市值 → 其余业务免费（sum-of-parts 下限护体）。

**模型映射**（与我们既有架构对齐）：
- = decision_sheet 的 worst-case band + R/R≥2:1 门——Klarman 版本更极端：**先验证 worst-case ≥ 0 再谈 upside**。
- 可筛因子：净现金 > 市值（net-net）；单一持股市值 ≥ 整体市值（stub value ≤ 0）；SOTP 下限 vs 现价。A股适配注意：需剔除现金受限/质押场景（用我们的质押解禁 Tushare 接口验证）。

### 2. 足够灵活（三层）

1. **节奏灵活**：现金是有价值的期权（cash-as-option），无猎物时可持有 50% 现金 → "不出手也是避免亏钱"。
2. **规模灵活**：机会出现时敢重仓（2008 年初见 Palatine 保证金强平信号，判定危机将至，一季度募 40 亿[NV]，危机中每天买入 1 亿美元）。
3. **品种灵活**：不锁定资产类别——雷曼倒闭买其**债券**不买股票（清算顺位：债权人优先受偿，股东垫底）→ 同一发行人资本结构内选 seniority 最优的敞口。

**模型映射**：
- 节奏灵活 = 我们的 NO_TRADE 诚实原则 + "每日计划是既有研究对象的状态而非每日荐股"（product_daily_plan_reanchor 已批准的同构原则）。**信号缺席本身是仓位。**
- 品种灵活 = A股语境下的可转债 vs 正股选择：同一发行人下行保护不同——筛"转债价格接近债底 + 正股 thesis 成立"的组合。

### 3. 自下而上（macro 是输入不是驱动）

原则：不做宏观预判驱动的投资（点名反对 Soros 式 top-down）；宏观只是因素之一。表达大趋势用**底层稀缺资产**而非高估值的直接标的——认可 AI 是大趋势，但不买大模型公司，买**有电力资源的土地**（芯片可以不停造，电力和土地是硬约束）。

**模型映射**：
- = 我们宪法的 factpack→thesis 顺序 + 行研只作 E2。宏观状态（RISK_ON/RISK_OFF）只做 execution gate 的仓位调节器，永不做选股信号。
- "趋势的稀缺瓶颈表达"是可复用的 thesis 模板：AI→电力/土地 ≙ 我们已有的 AI-Capex 四层学习栈（周期→政策→产业链→估值）里"产业链上找不可替代环节"。A股对应：算力租赁泡沫 vs 电力/IDC 土地资源股的估值分层。

### 4. 不迷信市场定价（forced-seller 机制库）⭐ 最可建模

原则：价格≠价值的偏离由**机制性强制卖出**制造，机会不来自"更聪明"而来自"对手盘被规则绑住了"。视频列举的机制：

| 强制卖出机制 | 可观测事件 | A股/HK 可得数据 |
|---|---|---|
| 指数剔除 → 被动资金集体卖出 | 指数调样公告日历 | 中证/恒指调样公告（定期、可预知） |
| 机构规则平仓（跌幅阈值/止损线） | 大跌后连续放量 | 我们执行门的资金结构分类（大单卖小单接） |
| 算法止损级联 | 盘中闪崩后回补 | TV 分钟数据 + 龙虎榜（T+1） |
| 分拆后市值过小 → 机构按章程强制抛售 | 分拆上市日历 | A股分拆上市案例可追踪（案例：Esterline 从 Emerson 分拆后跌破账上现金[NV]） |
| 保证金强平（危机模式） | 两融余额骤降 + 质押爆仓 | Tushare 两融/质押接口 ✓ |

**为什么值得立卡**：强制卖出家族**天然低换手**（事件驱动、每年有限次），机制不依赖预测（规则化卖方无法适应，alpha 不衰减于拥挤而衰减于规则改变）——恰好满足 QUANT_V0_VERDICT 后"新家族必须结构性低换手 BY DESIGN"的要求。⚠ 但 Quant 线 PAUSED（V3 admission 宪法，仅两个重启触发器）——**本文只入 Strategy Lab 货架做 strategy card 候选，不构成重启**。落地前还需过 8 条款 admission gate + dead-box embargo 检查（此家族用事件数据而非纯 OHLCV+季报，不触 embargo）。

## 与既有体系的三点冲突/张力（诚实记录）

1. Klarman 反宏观 vs 我们的 execution gate 用市场状态调仓——不冲突：他也承认宏观是"因素之一"，我们的用法（仓位调节不选股）恰在他的边界内。
2. Klarman 现金期权论 vs 我们周度 screen 的持续输出压力——需要守住：screen 输出 WATCH/NOT_ADVANCED 是合法结果，空仓周不是失败周。

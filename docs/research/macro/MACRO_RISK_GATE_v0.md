# 宏观风险修复门 MRG v0(四因子规则树)
> 蒸馏自 Junyan 2026-07-31 SOXL 四信号框架。核心公理(宪法级候选):
> **"股市负责制造情绪,信用市场负责告诉你长期资金去向"** → 信用因子持有否决权。
> 全部阈值为[初值,unvalidated],由判分校准;claim_allowed=false。
> 不是买卖指令;研究信号,human executes.

## 四因子定义(各 ∈ {绿+1, 黄0, 红-1})

**G1 情绪因子(VIX)** — 短期恐慌是否退潮
数据:^VIX(yfinance,免费)。
绿: VIX<20 且 5日方向向下 | 黄: 20≤VIX<25 或方向拉锯 | 红: VIX≥25 或 5日上行>15%

**G2 趋势支撑因子(SOX × KOSPI)** — 长期支撑是否守住
数据:^SOX vs MA100、^KS11 vs MA200(yfinance)。
绿: 双双站上支撑 | 黄: 任一在支撑±2%拉锯 | 红: 任一收盘跌破未收回
广度限定词:成分股>MA50 占比<40% 时绿自动降黄(原文 dispersion 警戒;数据可得后启用)

**G3 错位修复因子(相对强弱 z)** — 极端相对错位是否在修复
数据:z = zscore_120d(ln(SOX/SPX))。
绿: z 自 <-1σ 低谷回升且斜率>0,或 |z|<1(错位已平)| 黄: z<-1σ 未回升 | 红: z 创新低
⚠ 口径声明:这是原文"PCA market-neutral spread"的免费代理 — 测半导体对大盘的
相对错位,非因子中性化版本;两口径读数可以不同(首日实测即分歧:代理 +0.32σ vs
原文 +1.45σ),判分各记各的,不混同。

**G4 信用因子(美 IG 公司债 OAS)【否决权】** — 长期资金是否真愿意承担风险
数据:FRED BAMLC0A0CM(免费 CSV;本地网络需美东时段重试窗,失败标 DATA_BLOCKED)。
绿: 20日变化 ≤+5bp | 黄: +5~+15bp | 红: >+15bp 或绝对水平>1.0%

## 合成规则树(非加权平均 — 忠实原文逻辑)

```
G4=红            → CREDIT_VETO:一票否决,终态 RISK_OFF_BIAS(主升浪判定禁用)
四绿             → RISK_REPAIR_CONFIRMED(主升浪候选,趋势语义解锁)
三绿+G4黄        → TACTICAL_BOUNCE(战术反弹:条款单/小仓语义允许,禁重仓禁追涨)
其余组合         → MIXED(只观察)
任一因子 DATA_BLOCKED → 终态附 *_PARTIAL 后缀,缺哪盏灯必须显式列出
```

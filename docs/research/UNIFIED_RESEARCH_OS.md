# Unified Research OS v1.0 —— 研究方法熔炼宪法

> Junyan 2026-07-11 指令:"把所有研究方法熔炼掉,保证往后报告质量;core thesis
> 作为地基,SMC 及其他交易策略作为辅助。" 本文档是**唯一的方法索引 + 输出合同**。
> 它不重写各方法(避免分叉),只规定:金字塔怎么叠、两票制怎么门、周度 screen
> 的管线与格式**锁死成什么样**。与本文档冲突的旧描述,以本文档为准。

## 0. 为什么需要这份文档(问题诊断,留档)

同类 prompt 产出质量/格式漂移的根因:输出模板与数据拉取清单从未锁死,每次
screen 都是现场组装(方法散在 6 份文档),组装即方差。**修复 = 管线合同化:
允许变的只有市场内容;步骤、表格式、标签枚举、质量门永不变。**

## 1. 研究金字塔(唯一的分层结构)

```
L0 市场门(regime)      RISK_ON/WEAK_REPAIR/RISK_OFF/STYLE_ROTATION + CHURN_MODE
   └── 决定快层预算(CHURN/RISK_OFF ⇒ 快层新单预算 = 0)
L0.5 前兆层            流出衰竭 / 邻域新钱 / 防御拥挤 / 龙头背离 / 隔夜锚
   └── 只改变仓位节奏与注意力,不单独改方向结论
L1 Core Thesis(地基)   双支柱(能力壁垒E1+现金流翻译E1)· 六步法 · 三立场 ·
   8步协议 · 决策书资格审查 —— 回答"为什么是这家公司/这条链"
L2 执行辅助(timing)    SMC结构(BOS/CHoCH/sweep/premium-discount)× 资金门
   (五档资金结构)× 技术位 —— 回答"为什么是现在、在哪个价位结构"
L3 注册与判分          paper signal(wrong-if+horizon 必填)→ 定盘判分 →
   周报 → Memory 熔炼;n≥30 前一切胜率语言禁止
```

**SMC 与一切交易策略永远是 L2 辅助,不独立选股。** L2 没有 L1 时,产出只能叫
"结构观察信号"(paper-only,寿命 ≤3 天,永不入基金)。

**前兆层不是预言层。** 它回答"明天可能翻面的迹象是否在增加",只管理仓位曲线:
≥2 灯亮时停止给当前热门方向加仓,≥3 灯亮时允许小仓条款单进入人工复核,确认日
禁止追涨。每个前兆信号也必须进入判分池校准,未过样本门前不升级为规则。

## 2. 两票制(基金挂单的唯一入口)

模型基金注册任何 pending order,必须同时持有两张票:

- **票 1 · thesis 票(L1)**:慢层 = 双支柱/六步法产出;快层 = thesis-lite
  (板块逻辑一句 + 资金结构 + wrong-if,三者齐)。
- **票 2 · timing 票(L2)**:SMC 结构位合法(回踩承接/突破确认,premium>85%
  禁追)+ 资金门不逆 + L0 门通过 + R/R≥2。

缺任一票 ⇒ 只能是观察/paper signal。历史校准:紫金/牧原/恒瑞的注册均含
thesis-lite + 结构触发,合规;纯结构票(如退潮期首板)永远进不了基金。

## 3. 周度 Screen 管线合同 v1.0(锁死;变更需 Junyan 批版本号)

### 3.1 双层线与破线复核协议(v1.4,2026-07-24;起源:通富微电违约获益样本)

**问题诊断(留档)**:v1.3 及以前只有单一 stop。0724 实测暴露两个缺陷:
①单线把"论文证伪"与"账户生存"两件事混在一条线上;②"破线即市价执行"在恐慌
跳空开盘会卖在情绪最低点(0724 通富:开 68.03 触双线,若按合同执行实现 -10%,
盘中 V 型收复至成本区——违约方获胜,账本原样记录)。**修复执行设计,不修复
"线可以商量"——后者永远不修。**

**双层线定义(每笔 Paper List/实盘影子持仓必备):**

| 线 | 定义 | 来源 | 触发后 |
|---|---|---|---|
| **论文线** | 买入论文被证伪的结构位 | SMC 结构位/涨停起点/区间下沿 | **进入破线复核协议,不直接执行** |
| **灾难线** | 与论文无关的生存线 | 成本 -12% 与结构深位取更近者 | **无协议、无五查、无例外,触及即离场** |

**破线复核协议(论文线触发时,机器人+人共同执行):**

1. **固定五查**(全部为触发当刻可得数据,≤60 秒):
   ①所属板块当日资金方向 ②个股当日主力净额 ③是否恐慌跳空场景
   (开盘 15 分钟内 gap>2%,或 INDEX_MOVE 级指数告警同时在场)
   ④E1 有无新事实(公告/预告/否)⑤大盘守门状态(两道守门线)
2. **输出二选一**:`EXIT`(默认——五查无一为挽救项时必须选它)/
   `HOLD_TO_WINDOW`(五查中 ≥2 项为挽救项时允许,**至多顺延到下一执行窗口
   复核一次,不得二次顺延**)
3. **执行窗口纪律**:执行动作只在 **10:00 / 14:30** 两个定点窗口完成;
   **禁止集合竞价与开盘前 15 分钟的市价单**;执行采用限价或首次反抽。
   灾难线不受窗口约束——它随时生效。
4. **计数条款**:每次论文线触发 → 五查记录 → 结局(EXIT/HOLD 及其后 3 日
   定盘结果)全部进判分池;违约持仓(线内不执行)单独打标计数
   (0724 通富为违约获益第 1 例)。**本协议自身 n<30 前同样"计数中",
   不得声称优于单线制。**

## 5. 半衰期与拥挤度 doctrine(经验固化,计数中)

churn 市热点半衰期 ≈1 天(2026-07 第 4 次观察,[E3 计数中]):单日 RISK_ON /
单日板块爆发一律不构成 regime/趋势判定;升级需要**连续性**(连续 2 日资金 +
龙头广度 ≥2-3 名非 ST 确认 + 指数不逆风)。CROWDED 状态(资金 5 日累计前列 +
换手/涨停密度高)默认演化方向是 DISTRIBUTING,研究的边际价值在拥挤**前**与
回调**中**,不在追逐中。

## 5.5 推断层与 E1 层(v1.2 熔炼,2026-07-16)

**轮动实验室推断层**(`rotation_validation.py`,60 日回填 + 每日 --append):
Q1 HOT 存续率(Wilson CI)· Q2 龙头广度切分(Mann-Whitney)· Q3 链对
lead-lag(BH 校正)· 双负控制。首轮结果(校准先验,claim_allowed=false):
HOT T+3 存续仅 27%;**广度切分显著(z=4.23:有广度 +0.68% vs 无广度
-0.06% 前瞻中位)**;油服→油气、化药→医药流通两链对过 BH。
使用规则:这些是 Stage A 状态判定与快层三条件门的**校准依据**,不是信号;
升级为规则须跨窗稳定 + paper 前瞻 ≥30。

**图谱 E1 层**:行业锚 `sector_anchors.json`(TSMC 月营收 E1:4-6 月 yoy
17.5→30.1→67.9% 加速;SIA DATA_BLOCKED 人工)· 关系边 `relationship_edges.json`
(E2 边使用时须寻 E1 再确认)· E1 factpack 存 `docs/research/factpacks/`

## 5.6 前兆层(v1.3,2026-07-21)

半衰期≈1 天的市场里,只读昨天定盘会导致"判分正确、转化慢一拍"。前兆层补的是
确认前半天到一天的概率轮廓,固定五灯:

| 前兆 | 人话解释 | 当前机器口径 |
|---|---|---|
| 流出衰竭 | 还在流出,但已经卖不动 | `rotation_history` 里电子连续流出 + 跌幅边际收窄代理 |
| 邻域新钱 | 钱没离开科技,只是在内部换椅子 | 电子流出时,科技邻域多条子线正流入/收正 |
| 防御拥挤 | 防御股涨停潮本身可能是防御交易尾声 | 电力/公用事业涨停数代理 |
| 龙头背离 | 母板块弱,但领先子线先转强 | 子板块/邻域代理 + 最新日 nowcast 观察;个股结构仍需后续行情层 |
| 隔夜锚 | 华尔街先给 A 股科技 beta 指方向 | NVDA/SOX/TSM ADR/A50,缺源时 DATA_BLOCKED |

使用边界:前四灯由 `lead_precursor.py` 每晚用历史定盘回测并输出
`claim_allowed=false`;最新日可附带 `nowcast_log` 的 observation-only 个股证据,
但历史校准仍保持 settle-only;隔夜锚由 `overnight_anchor.py` 在盘前生成,缺数据源不得静默跳过。
前兆层只影响**加仓冻结/小仓复核/确认日禁追**三件事,不能独立生成买卖动作。

## 7. 强制规则 v1.5(2026-08-03 Junyan 定稿)

> 本章六条为**机器可执行的硬规则**,不是倡议。每条注明:规则原文 / 事故起源 /
> 由谁强制 / 违反后果。凡标注"闸门已在线"的条款,违反时由机器直接阻断;
> 标注"待接线"的条款,在接线完成前由人工审核强制,并列为最高优先工程债。

### C1 · 红旗闸门戳:名单层与下单层双覆盖

**规则**:任何研究名单(screen / 观察名单 / 候选池)与任何 paper 下单
(pre-registration / 条款单 / 基金挂单),**必须携带当日红旗闸门戳**
`{checked_at, verdict, latest_e1_date}`。无戳产出 = 违宪,不得进入判分池或基金账本。
红旗票**允许出现**(逆向/复活研究合法),但必须亮旗,且不得佩戴 ✅核心 层级或
获得 `PROMOTE_REVIEW_READY`。

**起源**:①2026-07-27 赛力斯 601127 —— 中报首亏预告(-15~-18 亿)发布 8 天后
仍被列入 ✅核心 名单;②2026-08-01 牧原 002714 庭审发现 —— **0711 发首亏预告
(-67 亿),0713 建仓**,登记论文写"中报改善"。前者是名单层漏检,
**后者证明下单层同样无闸门**,是红旗闸门诞生前的最后一笔遗留债务。

**强制方**:名单层 = `red_flag_gate.py --from-watchlist` + `setup_promoter.py`
的 `BLOCKED_RED_FLAG` 裁决(**闸门已在线**);下单层 = **待接线**(工程债 R-029,
在 `paper_tracker.py` / `model_paper_fund.py` 注册路径加戳校验)。

**违反后果**:名单层由机器阻断;下单层接线前,任何无戳下单在判分时标
`ENTRY_UNGATED`,且该笔不得计入任何能力统计。

### C2 · 六维强制完整性

**规则**:每次个股分析**必须完整运行六维** —— 行情 / 资金 / 基本面 / 技术 /
消息 / 估值。禁止"挑当下被强调的几个维度做"。分析先跑电池,后写观点;
输出必须携带完整性戳 `{covered, of: 6, missing[], verdict}`。

**起源**:2026-07-28 Junyan 指出"每次分析之后总会总结自己有哪一点没包括进去,
也就是现有 skills 每次只挑几个我强调的去做"。首次实测通富微电立即暴露三个
此前从未系统给出的事实(PE 处一年 93% 分位 / 毛利率三连降 / 距 52 周低 +187%)。

**强制方**:`full_battery.py`(**闸门已在线**,夜链 `--from-watchlist` 每晚全名单跑)。

**违反后果**:无完整性戳的单票分析 = 未完成品,不得作为研究结论引用。

### C3 · 缺维即 DATA_BLOCKED(缺数据 ≠ 通过)

**规则**:任一必要维度取不到数据时,该维标 `DATA_BLOCKED` 并写明原因,
整体完整性判 `PARTIAL`;**不得**用零值、空数组、历史值或默认值顶替,
**不得**因"没查到问题"而判 PASS。嵌套子检查的 `DATA_BLOCKED` 必须上浮到父维度。

**起源**:多起同类事故 —— ①红旗闸门零证据可查时曾判 PASS;②公告接口无权限时
曾伪装成"近 30 日公告数 = 0";③基本面内嵌闸门 `DATA_BLOCKED` 时电池仍报
`COMPLETE 6/6`;④一致性闸门自身用 `except: continue` 静默跳过损坏文件,
把最新报告改成 `BROKEN_JSON` 后 preflight 仍 PASS。

**强制方**:`red_flag_gate`(零证据 ⇒ DATA_BLOCKED)· `full_battery`(嵌套上浮)·
`consistency.scan_dirs`(五种 fail-closed)· `run_nightly` preflight
(**全部已在线**)。

**违反后果**:preflight FAIL ⇒ 当晚零引擎启动 + 报警旗 + 退出码非零。

### C4 · day-1 只能写"候选"

**规则**:任何基于**单日**读数(单日主力净额 / 单日指数动作 / 单日板块流向)的
判断,措辞**只能**是"候选 / 观察 / 待确认";**禁用**"确认 / 成立 / 已验证 /
唯一成立"。**只有 day-2 定盘延续**(同方向、同口径、独立第二日)之后,
才允许升格为"确认"。升格条件必须在 day-1 就写死并可机器判定。

**起源**:①2026-07-21 RISK_ON 孤日误判;②2026-07-29 我称"旭创是唯一确认主力
回流的",次日主力 -36.3 亿,升格条件未达成 —— **同一周内第二次犯同款病**。
判分教训拆两层:条款层 HIT(day-2 否决生效、零损失),定性层 MISS(措辞越权)。

### C5 · 独立事件簇 + 方向永久分列

**规则 5a(独立性)**:一切样本量门槛(含 `claim_allowed`、n≥30)按**独立事件簇**
计算,不按信号条数。簇集合必须与被计分集合使用**完全相同的过滤条件**
(方向明确 且 已有远期收益结果);中性/无结果条目不得撑门。

**规则 5b(方向分列)**:任何命中率 / 期望值 / 超额收益的报告,
**必须永久分列 constructive 与 cautious**,禁止混合汇总。两侧各自独立计算
样本量门槛,一侧达标不代表另一侧可 claim。

**起源**:①2026-08-01 审计 —— 122 条信号 `cluster_id` 为 0,同日同逻辑最多重复
5 条,但 scorecard 已打印 `claim_allowed=True`;审计构造 1 条可判 + 29 条 neutral
即可冲开门槛。②2026-07-28 归因审计 —— constructive 0.18(超额 -2.30%)
vs cautious 0.64(+2.47%),此前对外报的"0.55-0.63 池子命中率"是防守型判断
占比高把总数抬起来的,**不拆方向报胜率本身就是一次未遂的自欺**。

**簇的定义(提案,待 Junyan 批准后方可实施)**:按**论文来源**划簇 ——
同一 factpack / 同一假设 / 同一板块同一驱动 派生的全部信号归为一簇,
簇 id = `{论文来源标识}_{首次登记日}`。此为最严口径。
⚠ **此定义未批准前,`cluster_id` 不得落地,`claim_allowed` 恒为 false。**

**强制方**:`run_post_close_report.scorecard`(簇同过滤 **已在线**;
簇 id 生成 **待批准**)· `attribution_audit.py`(方向分列 已在线)。

**违反后果**:任何未分列或未按簇计数的统计结论,一律视为无效并撤回。

### C6 · 宏观门只影响优先级与风险预算

**规则**:宏观门(Macro Gate / MRG)的输出**只能**用于两件事 ——
①调整研究优先级(先看哪个方向)②调整风险预算(仓位上限 / 是否冻结新开仓)。
**不得**直接产生任何交易动作,**不得**作为方向预测器,**不得**单独构成
入场或出场理由。宏观档案与 MRG 契约必须标注 `mode: review_context_only`。

**起源**:2026-07-29 FOMC 事件档案 #001 建立后,存在把"宏观判断"直接转成
"仓位动作"的滑坡风险;MRG v0 的四因子阈值全部为 [unvalidated 初值],
未经判分校准,不具备预测资格。

**强制方**:`fetch_macro_gate.py` 输出携带 `mode: review_context_only`
(**已在线**);晋级前置门 **待接线**(工程债 R-031:MRG=RISK_OFF_BIAS 时
冻结晋级,但仍不产生卖出动作)。

**违反后果**:任何以宏观门为唯一理由的下单,判分时标 `MACRO_ONLY_ENTRY` 并作废。
